# Private Search Console HUD

This dashboard reuses TheWebGuy's Svelte reporting interface with Roof King identity and authenticated data loading. It is a separate private tool at /hud/, not an Astro marketing page or sitemap entry. Build assets are public code; analytics and credentials must remain outside public_html and Git. Read the client and server maps before changing either boundary.
