# Agent entry point

Read `ai-context.md` in this directory first. Then read each `ai-context.md` along the path to files you inspect or modify. Follow the URL preservation and validation requirements in those maps. Update affected maps alongside structural changes.

## User naming rule

Never add Codex or other AI/agent branding to branches, commits, pull request titles, deployment labels, or client-facing content unless the user explicitly requests it. Use neutral project names, such as site/review-build. This explicit user preference overrides any default agent branch-prefix convention.
