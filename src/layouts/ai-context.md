# src/layouts

PolishedServicePage composes 83 rebuilt service/location/cost/calculator routes from service-editorial.json using only native Astro sections and Svelte islands. Every rebuilt page has relevant service/topic tabs, independent review links, credentials, contextual products/brands, installation copy, estimate details, related links, FAQs and disconnected quote forms. Non-roofing credentials use exterior wording. ServiceLanding retains the approved /roofing/ reference. ServicePage remains for the existing GAF product catalog. Explicit native entry points prevent SiteLayout and WordPress compatibility styles from entering polished pages. DocumentLayout owns canonical metadata, preview noindex and shared business schema; polished pages add Service schema. ProductLayout remains independent. SiteLayout serves remaining legacy categories only.
